# Mohamad Ibrahim El Husseiny

Personal engineering and research portfolio.

**Website:** https://mohamad-elhusseiny.github.io/

This static website uses HTML, CSS, and JavaScript. It includes high-level architecture overviews and a browser-only image-resizing example. GitHub Pages publishes the root of the main branch.

## Pages

- index.html: portfolio, selected projects, experience, and contact
- research.html: a high-level research overview
- resume.html: printable resume
- sitemap.xml: canonical public pages for search discovery

## Content boundary

The portfolio provides a high-level overview of ongoing research. It does not distribute unpublished experimental grids, numerical results, protocols, source images, or lab data.

## Project branding

OGERO and AUB logos identify the organizations associated with the internship projects. The marks are sourced from the official [OGERO](https://ogero.gov.lb/) and [AUB/MSFEA](https://www.aub.edu.lb/msfea/Pages/default.aspx) websites.

No installation, API key, server, tracking service, or paid hosting is required.

## Public sample image

The image-resizing example uses a [CC0 photograph by Francisco Welter-Schultes](https://commons.wikimedia.org/wiki/File:Coccinella-septempunctata-20-fws.jpg), optimized to WebP. This public input example is separate from the research dataset. It makes no model calls and displays no unpublished results.
